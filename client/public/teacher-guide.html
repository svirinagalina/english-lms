⭐ Две самые важные функции

1️⃣ Mistakes — Записывать ошибки студента на уроке

КЛЮЧЕВАЯ ФУНКЦИЯ Это самое мощное средство для улучшения речи студента. Ошибки сохраняются и у вас, и у студента для повторения дома.

📝 Mistakes panel во время урока
💡 Можете оставить пусто — сосредоточиться на самой ошибке
Что происходит после записи:
  • У вас: ошибка попадает в историю студента в разделе Progress
  • У студента: ошибка видна в Mistake Notebook
  • Система анализирует: какая грамматическая тема это ошибка
  • Подсказывает: в Practice какие упражнения по этой теме выполнить для закрепления
  • Домашка: студент может потренироваться с этими ошибками дома в режиме Practice → Mistakes
💡 Как это работает в обучении: Вы отмечаете ошибку на уроке → система автоматически предлагает студенту потренироваться в похожих упражнениях → студент видит свою ошибку в контексте других похожих примеров → запоминает правило. Это намного эффективнее, чем просто сказать "это неправильно".

2️⃣ Dictionary + Vocabulary — Слова прямо с доски в словарь студента

КЛЮЧЕВАЯ ФУНКЦИЯ Студент встретил новое слово? За одно касание оно попадает в его словарь для практики. Три инструмента в одном:

Словарь на текстах и изображениях (подсветка + перевод + звук)
📝 Текст на доске:
He recommends reading this book to improve your vocabulary.
👆 Наведите на выделенное слово → появляется перевод и кнопки
🎤 При клике на слово:
🔊 Произношение (American English)
📖 recommends = советует, рекомендует
+ Vocabulary (добавление в словарь)

Студент нажимает + Vocabulary → слово автоматически попадает в его словарь раздел "From my board"

✓ Слово добавлено в словарь
✓ Система добавит его в Spaced Repetition
✓ Студент будет повторять его в подходящее время
+ Questions (для Speaking практики)

На слово можно нажать + Questions → система генерирует вопросы с этим словом

📌 "Do you recommend this book?"
📌 "What do you recommend to read?"
📌 "Can you recommend a good movie?"

👩‍🎓 Студент тренирует speaking с этими вопросами
Результат: словарь студента
📚 From my board — мой словарь (созданы на уроках)
recommends = советует, рекомендует 🔊
vocabulary = словарь, лексика 🔊
Что студент может делать:
  • Study = Учить все слова из набора в режиме Spaced Repetition
  • Review = Повторять слова, которые нужно повторить сегодня
  • Create card set = Создать свой набор карточек из этих слов для дополнительной практики

Другие полезные функции

Камера с размытием фона. Микрофон с автоматическим шумоподавлением. Всё работает из коробки.

Полезные советы

💡 Совет 1: Записывайте ошибки сразу во время урока

Не откладывайте. Пока вы говорите с студентом, нажмите "Record mistake". Ошибка свежа, контекст понятен. Студент вечером видит её в Mistake Notebook и может потренироваться.

💡 Совет 2: Добавляйте новые слова в словарь студента

На каждом уроке добавляйте 5-10 новых слов в его словарь через + Vocabulary. Они автоматически пойдут в Spaced Repetition, и студент будет их повторять без вашего участия.

💡 Совет 3: Используйте генерацию вопросов (+ Questions)

Если нужно отработать speaking с новыми словами — нажмите + Questions. Система сгенерирует вопросы, студент может потренироваться отвечать на них дома.

💡 Совет 4: Проверяйте Progress раз в неделю

Видите статистику: сколько упражнений выполнено, какие темы зависают, повторяет ли студент слова. Это подсказывает, на что сосредоточиться на следующем уроке.

FAQ

❓ Где записать ошибку студента?

Во время урока в левой панели нажимаете кнопку "Mistakes", заполняете форму. Правильный вариант писать не обязательно — можете оставить пусто.

❓ Студент может добавлять слова в словарь сам?

Да, когда вы кликаете на слово в словаре, показывается кнопка "+ Vocabulary". Студент может её нажать, и слово автоматически попадёт в его словарь.

❓ Когда система предлагает упражнения по ошибкам?

Сразу после того, как вы записали ошибку. Система анализирует грамматическую тему и в разделе Practice показывает, какие упражнения студент может выполнить для закрепления.

❓ Вопросы генерируются автоматически?

Да, когда вы нажимаете "+ Questions" на слово, система автоматически генерирует 3-5 вопросов с этим словом для speaking практики.

❓ Словарь студента хранится вечно?

Да, все слова из "From my board" остаются в словаре студента. Он может повторять их в любое время через Spaced Repetition или режим Cram перед экзаменом.
